# airtw 年度資料包的格式世代

> 實測自實際下載的檔案（1994、2010、2024），不是照文件抄的。
> 樣本保存在 `data/raw/_samples/`。

環境部的「全年逐時資料」在 1982–2025 之間**至少換過三種格式**。
解析器必須依年份分派，不能寫死單一 parser。

## 世代對照

| | 1994 世代 | 2010 世代 | 2024 世代 |
|---|---|---|---|
| 封裝 | ZIP，依空品區分資料夾 | ZIP，依空品區分資料夾 | ZIP，扁平 |
| 資料夾名 | `083年 中部空品區` | `99年 中部空品區` | （無） |
| 檔名 | `83年二林站_20180430.ods`/`.xls` | `99年二林站_20110329.csv` | `金門_2024.csv` |
| 檔案格式 | **ODS + XLS**（無 CSV） | CSV | CSV |
| 編碼 | （XML / OLE2） | **Big5** | **UTF-8 with BOM** |
| 欄位順序 | 日期, 測站, 測項 | **日期, 測站, 測項** | **測站, 日期, 測項** |
| 小時欄標頭 | `00`–`23` | **`1`–`24`** | `00`–`23` |
| 日期格式 | `1994/01/01` | `2010/01/01` | `2024/01/01 00:00:00` |
| 欄數 | 27 | 27 | 28（尾端多一個空欄） |
| 小數表示 | `0.33` | **`.33`**（省略前導 0） | `0.43` |
| 旗標位置 | **數值後綴** `15#` | **數值後綴** `12.3#` | **整格取代** `#` |
| 無效值的原始測值 | **保留** | **保留** | **遺失** |
| 含酸雨測項 | 是（PH_RAIN, RAIN_COND） | 是 | 否 |
| 隨附文件 | `.doc` / `.odt` ReadMe | — | — |

### 陷阱清單

1. **小時欄標頭 `1`–`24` vs `00`–`23`。**
   2010 世代第一欄是 `1`。依官方 ReadMe：「0時：指 0:00-0:59」，
   所以 `1` 對應的是 00:00–00:59，**不是** 01:00。標號差一格會讓整份資料位移一小時。

2. **欄位順序在 日期/測站 之間對調。** 不可用位置索引，必須讀表頭。

3. **`.33` 這種省略前導零的寫法。** 直接 `float()` 在 Python 沒問題，
   但某些 CSV 讀取器會判成字串。

4. **旗標語意在世代間改變（最重要）。**
   舊格式 `15#` 保留了測值 15；新格式 `#` 把測值整格丟掉。
   這代表**同一套缺漏填補策略，在新舊年代的效果不同**——
   長期趨勢分析必須對此做敏感度檢驗。

5. **1994 世代沒有 CSV。** 需要 ODS（zip + XML）與 XLS（OLE2）讀取器。
   兩者內容相同，優先用 ODS（純 XML，無二進位相依）。

## 官方旗標定義

逐字取自資料包內附的 `ReadMe_普通測站20170301.odt`：

| 符號 | 官方定義 |
|---|---|
| `#` | 表示儀器檢核為無效值 |
| `*` | 表示程式檢核為無效值 |
| `x` | 表示人工檢核為無效值 |
| `NR` | 表示無降雨 |
| 空白 | 表示缺值 |

2024 世代另出現 `NA`、`A`，未見於 2017 版 ReadMe，需另行查證。

## 🚨 風向哨兵碼

同一份 ReadMe 明載：

> 風向資料 **888 代表無風，999 則代表儀器故障**。

**這是本專案發現的最嚴重資料陷阱。**

2018 年的原始畢業專題把 `WD_HR`（風向小時值）當作一般線性連續變數
直接放進相關分析、迴歸與混合模型。若原始資料含 888/999，這些值會被
當成「888 度」「999 度」的真實風向參與運算。

原專題 p.35 的敘述統計顯示 `WD_HR` 最大值 312.99、平均 161.32——
因為先做了月平均，哨兵碼被稀釋而沒有明顯露出，但**污染仍然存在於平均值中**。

Phase 2 必須實測 2010–2017 逐時資料中 888/999 的出現率，
並量化其對原專題係數的影響。這會是「我當年錯在哪」章節最有力的一節。

> 另注意：即使沒有哨兵碼，對風向這種**circular variable** 取算術平均本身
> 就是錯的（0° 與 359° 平均會得到 179.5°，而正確答案是 359.5°）。
> 原專題的月平均風向從根本上不可解釋。

## 其他官方註記

- **2011 年格式變更**：「自 2011 年起由每日依監測項目多筆排列之順序修正為
  每日一筆資料呈現所有監測項目排列方式」——2011 是一個格式邊界年。
- **PM2.5 小時值的使用限制**：「PM2.5 自動監測尚無標準方法，其小時值僅供預警參考，
  不宜直接與 PM2.5 空氣品質標準之 24 小時值（35 微克/立方公尺）比較」。
  測量方法為貝他射線衰減法。原專題未提及此限制。

## 測站類型（1994 年 ReadMe 所載）

| 類型 | 站數 | 測站 |
|---|---|---|
| 一般空氣品質監測站 | 60 | |
| 工業空氣品質監測站 | 5 | 頭份、線西、麥寮、台西、前鎮 |
| 交通空氣品質監測站 | 6 | 鳳山、三重、中壢、永和、復興、大同 |
| 國家公園空氣品質監測站 | 2 | 恆春、陽明（恆春兼一般測站） |
| 背景空氣品質監測站 | 4 | 萬里、觀音、三義、橋頭（萬里、三義兼一般測站） |
| 參考測站 | 2 | 關山、埔里 |

原專題因「五種類別測站測項不同」而只採用所有測站共通的測項。
本專案改為**明確把測站類型當作模型變數**——交通站與背景站的
PM2.5 驅動因子本來就應該不同，這是資訊而非雜訊。

## 空品區

1994 年僅 7 區（中部、北部、宜蘭、竹苗、花東、雲嘉南、高屏），
**無離島**。2018 年起為 8 區（增加離島）。
跨年度比較「全台平均」時必須考慮測站組成的時變性。
