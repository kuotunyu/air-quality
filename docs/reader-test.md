# 非本科讀者試讀：要做什麼、怎麼做

這一步只能由本人執行，我無法代辦——需要的是「有人卡住了」這個事實，而那只有
真人能產生。`README.md` 的 Phase 8 release boundary 把它列為延後但不阻擋的驗收項目。

七個 prose gate 都在問「這個數字對不對」。這一步問的是另一件事：

> **一個不懂空氣品質的人，看完之後帶走了什麼？**

量的是**行為**，不是意見——他在哪裡停下來、哪裡跳過、哪裡以為看懂了其實看錯。

## 為什麼不能叫 LLM 代跑

它知道什麼是 conformal prediction、什麼是 PAF。請它「扮演外行人」得到的是
**它對外行人的模型**，不是一個人真的卡住。它每個字都用同樣的注意力讀，不會累、
不會放棄、不會滑過去——而那三件事正是要量的東西。

2026-08-22 委託另一個模型做的外部 review 是現成的示範：它把
「Prose-to-Data 零漂移」列為本專案的既有優點，而當時網站上正有三個漂掉的數字。
它稱讚了一件不成立的事。

模型在這件事上有用的是機械的那一半，而且多半是一次性稽核而非 gate：
術語首次出現未解釋（已成為 `scripts/check_term_first_use.py`）、主張出現在
證據之前、跨章矛盾、章與章之間未言明的前置知識。

## 準備

| | |
|---|---|
| **人** | 2–3 位，非理工背景。朋友、家人、同學都算 |
| **唯一條件** | **沒聽你講過這個專案** |
| **時間** | 每人 30–45 分鐘 |
| **工具** | 網址、計時器、一張紙。不需要錄影 |

## 現場

### 1. 開場（1 分鐘）

> 「我想看看這個網站好不好讀。**請你邊看邊把心裡想的講出來**——看到什麼、
> 在想什麼、哪裡覺得怪。沒有標準答案，你卡住的地方就是我要找的東西。
> 我不會回答問題，因為我想知道網站自己講不講得清楚。」

### 2. 給網址，然後閉嘴（25–35 分鐘）

**這是整件事最難的部分。** 他一定會問「這個是什麼意思」。回答：

> 「你覺得它想說什麼？」

或

> 「先照你的理解往下看。」

**你一解釋，這次試讀就作廢了**——真實讀者身邊沒有你。

### 3. 記三件事

停頓超過 5 秒就記，並記下他當時在看哪一段。

* **他在哪裡停下來**
* **他跳過了什麼**（捲動很快掠過的區塊）
* **他問了什麼**——一字不改地抄下來。那是網站沒講清楚的地方

不要記「他好像不太懂」。記**他實際說的話**。

### 4. 結束後三題（5 分鐘）

1. 這個網站在講什麼？
2. 最主要的發現是什麼？
3. 有哪裡你是跳過沒看的？

**第三題的答案通常最有價值**，而受訪者常不好意思講。先說「跳過很正常，
我就是想知道哪裡會被跳過」。

## 怎麼讀結果

只有 2–3 個人，**不要算比例**。看的是同一個地方被卡了幾次。

| 觀察 | 判讀 |
|---|---|
| 2 人以上卡在同一處 | 網站的問題，要改 |
| 1 人卡住 | 記著，不一定動 |
| 三個人對「主要發現」講出三種答案 | **最嚴重的訊號**——主論證沒有傳達到 |

### 這個網站特別值得盯的兩處

**第一章。** `web/src/components/StartHere.astro` 把「先看全台趨勢」標成
primary path，所以多數讀者從那裡進站，而它曾經是全站解釋最少的一章——
`holdout` 與 `R²` 的解釋是 2026-08-24 才補上的（`9819365`）。這正好是驗證
那次修補有沒有效的地方。

**首頁那句主張。** 「降了 60%；氣象標準化後的降幅比觀測值少 43%」。正確的讀法是
**模型標準化序列的降幅較小，但這個差額不能切成天氣與排放的因果貢獻**。如果讀者把
43% 說成「天氣造成」，或把剩餘比例說成排放／政策效果，就表示方法界線還沒有傳到。

## 什麼算做完

`README.md` Phase 8 的讀者試讀項目要能誠實標成完成，需要：

- [ ] 2–3 人做過，記錄留著
- [ ] 卡點列成清單，每項標「要改 ／ 不改 ／ 已改」
- [ ] 改完的部分重跑驗證：

```bash
uv run python scripts/check_like_ci.py
```

術語 gate 會告訴你解釋還在不在、離首次出現多遠。

不需要寫成正式報告，一頁筆記就夠。

## 我能接手的部分

「有人卡住了」這個事實只能由你產生。產生之後：

* 把記錄整理成待辦清單
* 判斷哪些卡點該改、哪些是這個題材無法避免的難度
* 寫修改草稿給你過目
* 改完跑完整驗證

**一句提醒**：不要因為某個卡點「解釋起來很麻煩」就跳過。這個專案的所有 gate
都建立在「量到什麼就報什麼」上，試讀結果也適用同一條規則。
