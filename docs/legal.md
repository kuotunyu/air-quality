# 授權、合規與再散布

> 本文件記錄實際查證的結果，不是法律意見。涉及發布決策處已明確標示。

## ✅ 已決定：只發布衍生產物，不散布逐時原始檔

**決定日期：2026-07-28。** 環境部的兩份授權敘述互相矛盾（詳見下方），
但這個矛盾**只影響一件事**：能不能把逐時原始值的完整複本上架 HuggingFace。

採取的做法是繞過它，而不是解決它：

| 發布 | 不發布 |
|---|---|
| ✅ L0 站-月、L1 站-日（**衍生統計產物**，任一種讀法都不算「轉載」） | ❌ L2 逐時原始值的完整複本 |
| ✅ 完整管線——任何人跑 `twair ingest` + `twair build` 就能自己重建全部資料 | |
| ✅ 分析程式碼、報告、圖表 | |
| ✅ **模型 demo 內的逐時樣本**（6 站 × 2025 全年，見下一節） | |

**沒有去函詢問，也不打算。** 這是個人的 side project，不是要投稿的研究，
不需要書面授權依據。管線公開就代表資料實質上仍然可得，
而 L2 是四項產出裡可替代性最高的一項。完整 L2 不列入後續發布工作；若未來要推翻
這個邊界，必須重新做法律與產品決策，不能把它當成既有 roadmap 的待辦。

Hugging Face Dataset 只封裝同一批 L0／L1 衍生統計。`twair export dataset` 只建立
本機 bundle，不會上傳；資料授權在 Dataset Card 中記為 `other`，不把程式碼的 MIT
授權誤套到資料上。

## ⚠️ 補記：逐時原始值其實已經公開了一份樣本

**記錄日期：2026-08-02。** 上面那張表寫成的時候，只想著 HuggingFace **dataset**
這條路；預報 Space 為了能跑，附帶了一個逐時樣本檔，而那件事沒有被任何人
拿到這張表前面比對過。這一節把它補上——**不是新的決定，是一件已經發生、
但當時沒有記錄的事**。

實測 `spaces/forecast/data/demo.parquet`：

| 量到的 | 值 |
|---|---|
| 列數 × 欄數 | 24,754 × 45 |
| 測站 | 6 個：前金、埔里、富貴角、忠明、潮州、馬公 |
| 時間範圍 | 2025-01-01 00:00 – 2025-12-31 23:00（逐時，整年） |
| 非空的原始 `PM2.5` | 24,754 筆（等於全部列） |
| 公開狀態 | Space `private: false`，`data/demo.parquet` 在公開檔案清單內，可直接下載 |

也就是說，**六個測站一整年的逐時原始值已經對外可取得**。

**判斷：留著，並且寫下來。** 上面那個 ❌ 寫的是「完整複本」，而這是 74 站裡的
6 站、44 年裡的 1 年：24,754 列對上 L2 的 340,371,384 列，是 **0.0073%**。
（第一版這裡寫「約 0.02%」，是估的；算出來不是那個數。）它存在的理由也不是散布資料，
而是那個 Space 沒有它就跑不起來：模型要有一段真實的近期序列才能示範預測。
把它拿掉會讓 Phase 7 的產出變成一個不能按的按鈕。

但**這個判斷本來就該在這裡，而不是靠事後稽核翻出來**。這份文件存在的目的
就是記錄這一類判斷；判斷可以是「在可接受範圍內」，前提是它被寫下來過。
照這個專案自己的標準，沒寫下來的決定等於沒做過決定。

若日後要縮小範圍，最小的改法是把樣本裁到一季（約 6,200 列），示範效果不變。
**目前不做，理由如上。**

**發布仍然沒有自動化。** 這裡原本寫著「`twair publish hf` 只推送 L0/L1」——
那個指令不存在。現在 `twair export dataset` 只會把 L0／L1 組成本機 bundle；
它不呼叫 Hugging Face API，也沒有 dataset 發布 workflow。Space 與 Dataset 的實際
上架仍是 owner 明確確認後才做的外部動作，因此建立 bundle 不等於發布，也不會讓
完整 L2 越過上面的邊界。

## 抓取行為準則

實作於 `src/twair/net.py`，全專案唯一的網路出口：

- **每主機最小請求間隔預設 1.0 秒**（`TWAIR_MIN_REQUEST_INTERVAL`）
- 指數退避重試，上限 5 次
- 可識別的 User-Agent，含專案網址供對方聯絡
- 所有下載寫入 `data/raw/_manifest.jsonl`（URL、SHA-256、大小、時間），
  重跑時比對後跳過，避免重複抓取
- 年度資料包為一次性大檔下載，非高頻輪詢

大量歷史資料一律走年度封裝檔，不用 API 分頁逐筆拉取——
既快得多，也大幅降低對方伺服器負擔。

## 第三方來源文件 —— 不再散布，不具名（已定案）

`懸浮微粒.pdf` 列入 `.gitignore`，**不隨程式碼發布**。除此之外，本專案採
**完全不具名**：

- **不提及任何私人的姓名**，中英文文件、網站、程式碼註解、
  commit 訊息一律適用。
- **不重製任何第三方文件的圖表、截圖或版面**。網站每一張圖、每一個數字
  都是本專案用原始資料重新計算的。

因此使用的只有兩類素材，兩者都不需要指名任何人，也不涉及重製他人的表達：

| 素材 | 為什麼可以用 |
|---|---|
| **方法選擇**（月平均、把 PM10 當解釋變數、風向線性化…） | 方法學事實。「某某做法會造成某某後果」的討論不依附於特定作者 |
| **已公布的數值**（β=0.4133、t=92.75、r=0.8865、VIF 等） | 事實性數據不受著作權保護，且可由本專案獨立重算驗證 |

如此一來，第 5 章不需要任何人的同意即可發布，也不會讓任何人因為一份
大學部作業被公開指名評論。

> 這件事的判斷標準不是「法律上能不能」，而是「有沒有必要」。
> 對照組要成立，需要的是那套方法，不是寫它的人。
